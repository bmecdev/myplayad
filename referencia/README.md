# Carpeta de Referencias para Nuevos Juegos (`referencia/`)

Coloca en esta carpeta cualquier archivo, imagen, documento, spritesheet, mockup o proyecto de referencia que desees que el **Agente Creador de Juegos (`/game`)** analice para construir o personalizar tu nuevo juego retro arcade en MyPlayAd.

---

### ¿Qué puedes poner aquí?
* 🎮 **Proyectos de código fuente base o prototipos** (archivos `.js`, `.html`, `.ts`, scripts).
* 🎨 **Sprites, imágenes de personajes, fondos o iconos** (`.png`, `.jpg`, `.svg`).
* 📜 **Reglas de juego, mecánicas, tablas de puntuación o documentos de diseño** (`.md`, `.txt`, `.pdf`).
* 🕹️ **Esquemas de controles para el móvil** (joystick, botones personalizados, inclinación, swipes).

---

El agente leerá automáticamente todo lo que agregues en esta carpeta al ejecutar el comando `/game`.
